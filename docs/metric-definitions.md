# 指标口径定义

改口径要先改这份文档，再改 `tests/`。代码和这里不一致时，以这里为准。

---

## 一、检索指标

设共有 `N` 道题，第 `i` 道题的 gold 在检索结果中首次出现的位置为 `r_i`
（1-based；未出现记 `r_i = None`，检索报错也记 `None`）。

### Recall@K

```
Recall@K = |{ i : r_i ≠ None 且 r_i ≤ K }| / N
```

**分母恒为 N，不剔除未召回的题。**

反例：10 道题里 5 道未召回，剔除后剩 5 道，其中 4 道在 @1 —— 剔除算得 0.80，
正确算法是 0.40。前者不是"召回率"，是"命中题的经验命中率"，换个名字才有意义。

### MRR

```
MRR = (1/N) · Σ [ r_i ≠ None ] · (1 / r_i)
```

未召回的题贡献 0，**不从分母里去掉**。

### error_rate

```
error_rate = 报错题数 / N
```

单独列出来，不并入召回率。**报错的题在召回计算里等同于未召回**——
它确实没给出可用结果，不该因为"不是模型的错"而被豁免。

### 延迟分位数

```
percentile(values, p) = 线性插值，位置 = (n-1) · p / 100
```

用 P95 而不是均值：均值被少数极慢请求摊平，而用户感受到的正是那几条慢的。

## 二、语料指标

### no_punct_ratio（无标点片段占比）

```
分子：len(text) ≥ min_len 且 text 中不含任何 `。！？!?`
分母：片段总数
```

**为什么设 `min_len`：** 标题、标签、短指令本来就不带句末标点。
把它们算进来会让比例虚高，也会让人误判问题规模。默认 20 字。

**这个指标的意义：** 它衡量"嵌入模型能不能看到语义边界"。
中文没有空格，标点是切分语义的主要信号。一个 200 字不带标点的片段，
嵌入出来的是一个笼统的"话题向量"，而不是可检索的具体内容。

真实项目里这个数字曾达到 48.7%，把标点重建做掉之后降到 0，
`Recall@5` 从 71% 提到 93.3%。同一个嵌入模型、同一套检索参数，只改了语料。

### duplicate_ratio（完全重复占比）

```
分子：每个重复组内 (出现次数 - 1) 求和
分母：片段总数
```

例：`["A", "A", "B"]` → 分子 1，分母 3 → 0.333。

按"多出来的槽位"算而不是按"重复组数"算，因为我们要知道**top-k 里会有多少位置被浪费**。

### near_duplicate_pairs（近重复对）

```
对 i<j 计算 3-gram Jaccard，≥ 阈值则计一对
```

**阈值必须按片段长度校准。** 实测：25 字的中文片段只改一个字，
Jaccard 就从 1.0 掉到 0.77。短片段用 0.9 等于不检测。

参考取值：

| 片段典型长度 | 建议阈值 |
|---|---|
| 几十字（问答对、短段） | 0.70 – 0.80 |
| 一两百字（段落） | 0.85 – 0.90 |
| 几百字以上（长文档） | 0.90 – 0.95 |

### ascii_punct_ratio（半角标点占比）

```
分子：半角标点 `, ? ! : ;` 的数量
分母：半角 + 中文标点的总数
```

偏高的片段通常经过多次转手（表格导出、程序拼接、复制粘贴），
往往还伴随其他脏数据。它更像是"这个片段值得人工看一眼"的提示。

## 三、配对对比

### 变好 / 变差 / 不变

```
before = r_i（基线）；after = r_i（改动后）
未召回视为 +∞
after < before → 变好
after > before → 变差
after = before → 不变
```

### identical

```
identical = (所有题的 rank 序列完全相同)
```

**这是最重要的一个信号。** 改了参数、换了模型，但每一题排名一字不差，
说明改动大概率**没有真正生效**：

- 配置写进了文件，但程序读的是另一份
- 结果走了缓存
- 平台/SDK 静默忽略了这个参数
- 参数改了但请求体里没带上

遇到 `identical`，先验证参数确实到达了检索端，再谈效果。
否则你会把"没生效"解释成"影响不大"，然后在这条死路上继续试参数。

## 四、没做什么

- **不计算忠实性（faithfulness）**：需要 LLM 判断 + 人工复核，不适合放进零依赖库
- **不计算答案相关性**：同上，且主观性强，没有稳定口径
- **不做统计显著性检验**：题量通常只有几十道，检验的功效很低，
  与其给一个 p 值，不如把逐题 diff 摊开给人看
